\# SIH (26) - Anti-Drone System



Smart India Hackathon 2026 project.



\## Overview



An anti-drone system combining radar, computer vision, STM32-based control, and a 2-axis gimbal for drone detection, tracking, target lock, and system response.



\## System Flow



Radar + Camera

&#x20;      ↓

Drone Detection

&#x20;      ↓

Data Fusion

&#x20;      ↓

Target Tracking

&#x20;      ↓

2-Axis Gimbal

&#x20;      ↓

Target Lock

&#x20;      ↓

System Response
